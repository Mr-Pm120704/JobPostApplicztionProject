# Jobify Frontend (Vite + React + TypeScript + Tailwind)

This is a production-ready React frontend scaffold for a job posting application with role-based access:
- Roles: `jobseeker`, `recruiter`, `admin`
- Features: authentication, role-based routing, job search, dashboards, chat support, course enrollment (payment integration), file uploads.

## How to run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```

This repository is a frontend only. Configure API base URL using `src/config.ts`.

Assets, icons, and fine-grained styling should be added to match your brand.
